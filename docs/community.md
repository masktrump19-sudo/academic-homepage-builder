# Community launch drafts

Publish only after the tagged release and deployment walkthrough are verified.

## English

I built Academic Homepage Builder, an open-source local wizard for academic websites.

Import a résumé, review the extracted content, choose one of three layouts, and
export a static site or an editable source project. It supports English, Chinese,
and bilingual pages, with an optional Codex workflow or a ChatGPT collaboration pack.
The basic workflow needs no AI account and keeps résumé processing on your computer.

The aim is one-click generation with a clear GitHub + Cloudflare deployment guide.
You still control the first account authorization and everything that becomes public.
For later papers and projects, reopen the same source project and update it.

[Try the template gallery](https://academic-homepage-builder.pages.dev/) — static,
fictional examples; résumé importing happens in the local builder.

[Code and documentation](https://github.com/masktrump19-sudo/academic-homepage-builder)

MIT licensed. Feedback on import accuracy, accessibility, and templates is welcome.
Please use fictional or redacted examples when reporting issues.

## 中文

我开源了 Academic Homepage Builder：一个在本机运行的个人学术主页生成器。

导入简历、核对信息、选择模板，就能导出可发布的网站和可维护的源码。
提供学术双栏、现代简洁、视觉作品三套布局，支持中文、英文和双语。
基础功能不需要模型账号；也可以选择 Codex 辅助，或者把协作包交给自己的 ChatGPT／Codex。

简历默认在本机处理，公开内容由本人确认。项目提供 GitHub＋Cloudflare 的部署教程：
一键生成，首次账号授权由使用者完成。以后有新论文、新项目，继续编辑同一份资料即可。

[在线模板演示](https://academic-homepage-builder.pages.dev/)：仅展示虚构人物的静态主页，
简历导入在本地向导进行。
