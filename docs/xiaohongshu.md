## 标题

把简历变成学术主页，我开源了

## 正文

做学术主页，整理内容、改样式、研究上线流程都挺花时间。我把这套流程做成了一个采用 MIT 许可的开源工具 Academic Homepage Builder，刚开始做科研也能用。

用虚构的“小明”演示：导入文字型 PDF、DOCX、TXT，或粘贴简历 → 核对信息 → 选模板 → 一键生成。没有论文也能开始，空栏目自动隐藏。

📚 学术双栏：按论文、项目、经历组织内容
🪶 现代简洁：留白多，适合简短介绍
🧩 视觉作品：项目配图更突出
支持中文、英文和双语，也能预览手机效果。

简历默认在本机解析，不上传到项目作者的服务器；头像和公开 CV 要另选。安装依赖需要联网，AI 默认关闭，只有你选择并确认文本后才调用。

导出后按教程连接自己的 GitHub 和 Cloudflare Pages。“一键”指生成网站，首次登录、授权和域名设置仍由本人完成。以后有新论文或项目，导入源码包继续改就行。

图中“小明”及成果均为虚构演示。欢迎试用，也欢迎提建议！

GitHub：https://github.com/masktrump19-sudo/academic-homepage-builder
