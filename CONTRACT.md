# Implementation contract

Internal integration notes; no personal data is permitted in this repository.

- Python package `ahb`, Python >=3.12. Models in `ahb/models.py` (owned by core agent).
- `Site` Pydantic model with `schema_version=1`, `languages: list[en|zh]`, `default_language`, `template: academic|modern|visual`, `accent` hex, `font: serif|sans`, `theme: light|dark|auto`, `site_url` optional HTTPS origin, `example: bool`, `profile: Profile`, `sections: dict[str,list[Entry]]`, `hidden_sections: list[str]`, `contact: Localized`, `hobbies: Localized`. Localized is `dict[str,str]`, en/zh keys. No automatic translation fallback between languages.
- Profile: localized `name, headline, affiliation, bio, interests`; string `email, portrait, cv`; `links: list[Link]`. Link has `label,url`.
- Entry: localized `title,subtitle,description,status`; string `date,authors,url,image`; `links: list[Link]`; bool `confirmed=False, enabled=True`. Section keys: news,publications,projects,internships,education,honors. Empty sections hidden. `hidden_sections` are user overrides.
- Image/CV fields accept only paths `assets/uploads/<safe filename>`; no remote images. `Link.url`/Entry.url permit HTTPS, profile email is separate. All textual fields are plain text.
- Parser: `parse_resume(filename: str, payload: bytes) -> dict` returns `{text, site: Site.model_dump(), warnings: list[str]}`; `parse_text(text: str)` same shape. No file persistence; no networking. Supported PDF/DOCX/TXT. Import is tentative, never approved automatically.
- Renderer: `render_site(site: Site|dict) -> dict[str,bytes]` includes language HTML, locally served CSS/JS, favicon, robots/sitemap only when valid site_url set. No uploaded bytes handled here. `render_page` not required as public API. Assets-relative links must work from language subdirs. Preview uses same static renderer.
- API owned by root. GET `/api/config` -> `{token,schema,blank,demo}`. POST mutations require `X-AHB-Token` plus same-origin check. Root HTML sets no raw user text.
- POST `/api/parse` multipart `file`; POST `/api/parse-text` JSON `{text}`. GET `/api/codex/status`. POST `/api/ai` JSON `{text,consent:true,languages:[...], model?:string}` -> parse shape. POST `/api/assist-pack` `{text,languages}` -> ZIP.
- POST `/api/assets` multipart `file` -> `{id,path,name,mime,size}`; assets only in per-process memory and require explicit public selection. POST `/api/preview` JSON `{site,asset_ids,reviewed:false}` -> `{url}`. POST `/api/export` JSON `{site,asset_ids,reviewed:true,kind:'static'|'source'}` -> ZIP. Preview URL protected by unpredictable id; iframe display. DELETE `/api/session` clears temporary assets/previews.
- POST `/api/import` multipart project ZIP or site.json -> `{site,assets:[...],warnings}`. ZIP contains public site.json and selected assets only; raw resume/AI source excluded. Model import doesn't imply review. Frontend can also validate JSON through config schema/server preview.
- Source export contains standalone `site.json`, `assets/uploads`, ahb minimal build package, dependency pins, build.py, README and licenses; default Cloudflare command `pip install -r requirements.txt && python build.py`, output `dist`. Draft restoration reads source export.
- Root core build: `build_project(site, assets:dict[path,bytes], out:Path)` + `check_directory(out)`; all builds stage fresh output, must never recursively delete unrelated directory. Reject nonempty output unless marker establishes previous AHB build. `ahb build --project PATH --output PATH`, `ahb check PATH`, `ahb serve`.
- Frontend owned by UI agent (`ahb/web/*`), renderer/static site styles (`ahb/render.py`, `ahb/site_assets/*`). Models/parser and parser tests owned by core agent. Root owns server, exporter, CLI, AI adapter and integration tests. Docs agent owns README/docs/licenses/CI/privacy audit script; coordinate test paths.
- Fictional demo only: Alex Morgan / 林知远, Example University / 示例大学. Mark example=true and visible 'Fictional demo' banner; no real people, institution logos, papers or owner contact details. Demo domain empty until deployment assigns actual hostname. Example URLs use example.org or no URL.
