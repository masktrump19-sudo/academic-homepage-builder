ONLY WHAT YOU APPROVE

The source project is editable and re-importable. Neither export includes your original resume, AI input, or unchecked files.

Make it live, with your accounts

  1. 1

    Save your source to GitHub

    Unzip the source project and create your own repository. A private repository is a sensible default.

  2. 2

    Connect Cloudflare Pages

    Choose Git integration and authorize only this repository. Use the build command below and set the output directory to dist.

    pip install -r requirements.txt && python build.py
  3. 3

    Confirm your address

    Pages supplies a pages.dev address. Add that actual URL above, export again, and push the updated source. Future pushes deploy automatically.
